# Learning About Version Control
Author: Molly Kessler

Solving merge conflicts takes conscious effort, but I can do it!

The thing I like most about version control is that I can go back and look at my old code when I delete something that I thought I didn't need anymore, but then later realized I wanted to use in a different way.

Something I find challenging about version control is getting too in-the-zone and forgetting to commit regularly, leading to large, unwieldy commits with lots of changes.
